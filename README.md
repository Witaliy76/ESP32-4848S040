## 🎯 Описание

Порт проекта **yoRadio** для модуля **ESP32-4848S040** с дисплеем **ST7701 RGB Panel 480x480**.

### Технические характеристики

| Компонент | Характеристики |
|-----------|----------------|
| **Процессор** | ESP32-S3-WROOM-1-N16R8 (240MHz, dual-core) |
| **Память** | 520KB RAM + 16MB PSRAM + 8MB Flash |
| **Дисплей** | ST7701 RGB Panel 480x480 (16 линий данных) |
| **Тачскрин** | GT911 (I2C: SDA=19, SCL=45) |
| **Аудио** | I2S (BCLK=1, LRCLK=2, DOUT=40) |
| **Подсветка** | PWM (пин 38) |
| **SD карта** | FSPI (CS=42, SCK=48, MISO=41, MOSI=47) |

### Аудио выход

![DAC Connection](https://github.com/user-attachments/assets/c49b36b6-3b10-4db5-ad03-bf7ecc4aca3d)
*Порядок подключения DAC к заднему разъему*

![Module Back](https://github.com/user-attachments/assets/e45c9c79-ed04-4fc9-8e6e-d9d97bda08d4)

**Встроенный моно DAC:**
- По умолчанию отключен (пины на задний разъем)
- Для включения: запаять перемычки R21, R22, R23
- Если задний разъем не используется: R26, R27, R25 можно не выпаивать

## 🔧 Быстрый старт

### 1. Сборка проекта

```bash
# Клонировать репозиторий
git clone https://github.com/your-repo/ESP32-4848S040.git
cd ESP32-4848S040

# Собрать и загрузить
pio run -t upload
pio run -t uploadfs  # Загрузить SPIFFS (рекомендуется)
```

### 2. Русская локализация

Заменить файл шрифтов:
```
.platformio/libdeps/yoradio-esp32s3/GFX Library for Arduino/src/font/glcdfont.h
```
На файл из `fonts/glcdfont.h` (в репозитории).

### 3. Оптимизация для больших битрейтов

**⚠️ ВАЖНО:** Для стабильной работы на битрейтах >192 kbps замените библиотеки:

**Путь:**
```
<user>/.platformio/packages/framework-arduinoespressif32-libs/esp32s3/lib/
```

**Файлы для замены:**
- `libesp_netif.a` → из `library!/esp32s3_5.4/libesp_netif.a`
- `liblwip.a` → из `library!/esp32s3_5.4/liblwip.a`

**Поддерживаемые версии:** ESP-IDF 5.4, 5.5

> После замены: перезапустите PlatformIO и перекомпилируйте проект.

## ⚠️ Первый запуск

### Форматирование SPIFFS (erase_flash)

При первом запуске после `erase_flash`:

- ⏱️ **Ожидайте ~60 секунд** с черным экраном
- 📦 Происходит автоматическое форматирование SPIFFS
- 🔆 Подсветка может быть выключена
- ✅ Это **нормальное поведение** — просто подождите

**Рекомендация:** Используйте `pio run -t uploadfs` для быстрого старта.

## 🐛 Известные проблемы

### ⚠️ SD Card Playback Issue

**Статус:** Индексация работает, воспроизведение зависает.

**Проблема:**
- SD карта инициализируется и индексируется корректно
- При нажатии Play система зависает в `config.loadStation()`
- `SDPLFS()->open()` работает при загрузке, но не работает во время воспроизведения

**Технические детали:**
- Board: ESP32-S3 N16R8
- Display: ST7701 RGB (VSPI)
- SD Card: FSPI (CS=42, SCK=48, MISO=41, MOSI=47)
- Audio: I2S (без конфликтов SPI)

**Что пробовали:**
1. Смена SPI с FSPI на HSPI — без эффекта
2. Mutex timeouts и forced release — без эффекта
3. Упрощение cardPresent() — без эффекта
4. Suspend display task — без эффекта

**Гипотеза:** Проблема в слое файловой системы SD, а не в SPI или mutex.
